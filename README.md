# Life-Tracker
Study project: clever organizer with taskboard option and time-management addition

## Installation:
```bash
git clone https://github.com/Anastasia-Paliy/Life-Tracker.git
cd Life-Tracker
pip install -r requirements.txt
```

 * Delete `notes.db` in order to start adding your own notes
 * Run `main.py`

## Stack:
* Python 3.9
* PyQt5
* SQLite3
